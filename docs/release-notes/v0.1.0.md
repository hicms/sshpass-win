## sshpass v0.1.0

First release. `sshpass` gives Windows non-interactive ssh password
authentication. It runs a command inside a Windows pseudo console (ConPTY),
waits for the password prompt and types the password for you, so `ssh`, `scp`,
`sftp` and `rsync -e ssh` can run from scripts.

### Features

- **Five password sources**: `-p password`, `-f file` (first line), `-e` (the
  `SSHPASS` environment variable), `-d handle` (an inherited handle) or
  standard input, which is read with echo turned off.
- **Custom prompts**: `-P text` changes the text that marks a password prompt
  (default `password:`). Prompts split across output chunks are still found.
- **Host keys**: `-k` (`--auto-confirm`) answers "yes" to the unknown host key
  question. Without it, sshpass stops with exit code 6 instead of hanging.
- **Wrong password detection**: a repeated prompt stops the command with exit
  code 5.
- **Exit code passthrough**: once logged in, the command's own exit code is
  returned unchanged.
- **Arguments arrive intact**: spaces, quotes, backslashes and empty arguments
  are quoted with the Windows command-line rules.
- **Interactive use**: keystrokes (including Ctrl+C), colors, Unicode text and
  window resizes are relayed to the command.
- **Clean output**: the echoed Enter after the password and the pseudo
  console's own mode-switch sequences are not written to your output, so
  redirected output contains only what the command printed.
- **Careful with secrets**: the password is wiped from memory when it is no
  longer needed, and `-v` never prints it.
- **Small and self-contained**: one static executable (about 370 KiB) that
  needs no Visual C++ runtime.

### Exit codes

| Code | Meaning                                                  |
| ---- | -------------------------------------------------------- |
| 0..  | The command's own exit code                              |
| 1    | Invalid arguments                                        |
| 2    | Conflicting password sources                             |
| 3    | Runtime error (unreadable password, command did not start) |
| 5    | Incorrect password                                       |
| 6    | Host public key is unknown (use `-k` to accept it)       |
| 7    | Host public key for the IP address has changed           |

### Requirements

Windows 10 version 1809 (build 17763) or later, 64-bit, and an ssh client such
as the OpenSSH client that ships with Windows.

### Installation

1. Download `sshpass.exe` and `sshpass.exe.sha256` from the assets below.
2. Verify the download in PowerShell:

   ```powershell
   $expected = (Get-Content .\sshpass.exe.sha256).Split(' ')[0]
   $actual = (Get-FileHash .\sshpass.exe -Algorithm SHA256).Hash.ToLower()
   if ($actual -eq $expected) { 'OK' } else { 'MISMATCH' }
   ```

3. Put it in a folder on your `PATH`:

   ```powershell
   $dir = "$env:LOCALAPPDATA\Programs\sshpass"
   New-Item -ItemType Directory -Force $dir | Out-Null
   Copy-Item .\sshpass.exe $dir
   $path = [Environment]::GetEnvironmentVariable('Path', 'User')
   if (($path -split ';') -notcontains $dir) {
       [Environment]::SetEnvironmentVariable('Path', "$path;$dir", 'User')
   }
   ```

4. Open a new terminal and run `sshpass -h`.

To uninstall, delete the folder and remove it from your user `PATH`.

### Usage

```powershell
# Password from an environment variable (preferred over -p)
$env:SSHPASS = 'secret'
sshpass -e ssh user@host uptime

# Password on the command line (visible to other processes)
sshpass -p secret ssh user@host ls

# Accept an unknown host key automatically
sshpass -k -e ssh user@host hostname

# rsync through a specific ssh client
sshpass -e rsync -avz -e "C:/path/to/ssh.exe" file user@host:/tmp/
```

Options stop at the first argument that is not an option; everything after it
belongs to the command. Run `sshpass -h` for the full option list.

### Known limitations

- Windows only.
- `-p` puts the password on the command line, where other processes can see
  it. Prefer `-e`, `-f` or standard input.
- sshpass is meant for password authentication. If the command never asks for
  a password (for example a key logs you in), its output is not shown, but its
  exit code is still returned.
- Keystrokes are relayed only when sshpass runs in a console. Piped standard
  input is used as the password source, not passed on to the command.

### Verifying the download

`sshpass.exe.sha256` holds the SHA-256 checksum of `sshpass.exe` in the
`<hash>  sshpass.exe` format.
